# Excel-Projects

📊 Advanced Excel Business Analytics Dashboard

A comprehensive Excel-based business analytics project demonstrating advanced spreadsheet skills, including HR analytics, payroll calculations, inventory management, pivot tables, dashboards, conditional formatting, and data visualization.

🚀 Project Overview

This project simulates real-world business operations by combining employee attendance tracking, payroll processing, inventory management, and executive reporting into a single Excel workbook.

The goal is to showcase practical Excel skills commonly used in Business Analysis, Data Analysis, Operations Management, and Financial Reporting roles.

✨ Key Features
👥 HR & Payroll Analytics
Employee attendance tracking for 20 working days
Automatic calculation of:
Total Present Days
Total Absent Days
Sick Leave Count
Vacation Leave Count
Total Hours Worked Calculation
Gross Pay Calculation based on hourly rates
Department-wise salary analysis
Average Hourly Rate by Department using AVERAGEIF()

Product inventory tracking
